# 三个 Skill 设计练习

三个练习共用指导学习领域，分别练习诊断、引导和复盘，避免同时引入多个不相关业务。

| Skill | 输入 | 关键分支 | 可验证产出 |
|---|---|---|---|
| diagnose-mistakes | 错题与学生作答 | 信息不足则补充；区分计算与概念 | 每条误区绑定证据 |
| guided-practice | 当前知识点与尝试记录 | 按独立完成情况逐级提示 | 提示等级与后续独立作答 |
| weekly-learning-review | 任务与测验记录 | 缺数据不推测；未完成目标重新安排 | 数据来源、变化与下一步 |

正文都应声明完成条件、失败路径与依赖工具。只有需要写入学习状态时才提出写动作，由运行时处理权限。

可阅读 [学习导师插件](../../examples/learning-coach-plugin/README.md)，观察标准 SKILL.md 如何携带教学参考资料。Plugin 负责封装与组件发现，Skill 保持 Agent Skills 格式；文件加载到本教程 Runtime 仍需宿主适配器。

## 动手要求

先实现一个 Skill 并完成 [回归评测](evaluation.md)，再组合多个 Skill。组合时明确谁产生什么结构化结果，哪些事实可以进入长期记忆，失败后由谁请求人工帮助。

没有证据的“学生能力较差”不能写成长期状态；一次运行的改进经验也不能直接发布为所有用户的教学政策。
