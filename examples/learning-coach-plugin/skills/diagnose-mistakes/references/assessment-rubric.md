# 诊断标准

先确认题目要求，再定位学生最早出现的偏差。不要根据最终答案猜测缺失的解题过程。

| 类型 | 可观察证据 | 验证方式 |
|---|---|---|
| 概念理解 | 定义、条件或数量关系使用错误 | 换一个小例子，请学生解释条件 |
| 解题策略 | 选择的方法无法满足题目目标 | 比较两种方法的适用前提 |
| 步骤或计算 | 前提正确，某一步推导或计算出错 | 让学生重做该步并说明依据 |
| 表达 | 方法可能正确，但单位、符号或说明缺失 | 要求补齐对应表达 |

多种解释都可能成立时，先提出一个最能区分它们的问题。区分观察事实、推断和仍待确认的内容；诊断描述当前作答，不给学生贴能力标签。
