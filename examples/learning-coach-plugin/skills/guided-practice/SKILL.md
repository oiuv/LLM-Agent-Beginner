# 引导练习

1. 确认要练习的知识点和完成条件。已有题目时使用该题；否则生成一道围绕单一目标的短题。
2. 先请学生尝试，等待回复，不在同一轮提前给出完整解答。
3. 参考 [提示阶梯](references/hint-ladder.md)，从最低必要级别给出一个提示。
4. 等待新的尝试，记录可观察到的步骤和本次提示级别。学生仍无法推进时才升级提示。
5. 核验整数加法时，可使用宿主提供的 MCP add 工具；仅调用已发现且被允许的工具。工具不可用时说明未执行工具核验，不伪造结果。
6. 达到完成条件后，请学生解释关键方法；如需进一步验证，再给一道短变式题。
7. 总结“独立完成”或“在某级提示后完成”，不把一次成功写成长期掌握结论。

用户取消或达到约定的练习时限时结束。发现题目歧义或答案无法可靠确认时说明问题并请求澄清。正在进行的受监督考试中只提供方法引导，不代做当前题目。学习记录写入与提醒安排由宿主授权和执行，不由 Skill 自行启用。

完成前检查：每次提示后有新尝试，结论对应实际证据，未为了延长互动追加无意义的题目。
